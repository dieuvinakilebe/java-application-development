# Краткое объяснение по заданиям

## 1. Итератор

**Условие.** Реализовать собственный интерфейс итератора с методами `hasNext()` и `next()`.

**Решение.** Создан интерфейс `MyIterator<T>`. В `MyArrayList<T>` есть внутренний итератор, который проходит элементы массива по индексу.

**Ответ.** Итератор позволяет последовательно обходить коллекцию без прямого доступа к ее внутреннему массиву.

## 2. Список

**Условие.** Реализовать динамический список с добавлением, удалением, получением и изменением элемента.

**Решение.** Создан `MyArrayList<T>` на основе массива `Object[]`. Когда места не хватает, массив расширяется в 2 раза.

**Ответ.** Список работает как простой аналог `ArrayList`.

## 3. Хеш-таблица

**Условие.** Реализовать ассоциативный массив с методами `put`, `get`, `remove` и обработкой коллизий.

**Решение.** Создан `MyHashMap<K,V>`. Коллизии обрабатываются цепочками: в одной ячейке массива хранится связанный список узлов.

**Ответ.** Можно хранить пары ключ-значение и получать значение по ключу.

## 4. Singleton с ленивой инициализацией

**Условие.** Реализовать потокобезопасный Singleton, который создается только при первом обращении.

**Решение.** Создан `LazySingleton` с `volatile` и double-checked locking.

**Ответ.** Экземпляр создается один раз при первом вызове `getInstance()`.

## 5. Singleton с жадной инициализацией

**Условие.** Реализовать Singleton, который создается при загрузке класса.

**Решение.** Создан `EagerSingleton` со статическим финальным полем `INSTANCE`.

**Ответ.** Экземпляр создается сразу при инициализации класса.

## 6. Стек

**Условие.** Реализовать структуру Stack с методами `push`, `pop`, `peek`.

**Решение.** Создан `MyStack<T>` на массиве. Последний добавленный элемент извлекается первым.

**Ответ.** Стек работает по принципу LIFO.

## 7. Очередь

**Условие.** Реализовать очередь FIFO с методами `enqueue`, `dequeue`, `peek`.

**Решение.** Создан `MyQueue<T>` на кольцевом массиве.

**Ответ.** Очередь работает по принципу FIFO.

## 8. Сортировка

**Условие.** Реализовать QuickSort и MergeSort.

**Решение.** Создан класс `SortingAlgorithms` с двумя статическими методами.

**Ответ.** Оба алгоритма сортируют массив чисел по возрастанию.

## 9. Бинарный поиск

**Условие.** Реализовать бинарный поиск для отсортированного массива.

**Решение.** Создан `BinarySearch.search(int[] array, int target)`.

**Ответ.** Метод возвращает индекс найденного элемента или `-1`, если элемента нет.

## 10. Factory Method

**Условие.** Реализовать фабричный метод для создания объектов разных типов.

**Решение.** Создан `ShapeFactory`, который создает `Circle`, `Rectangle` и `Triangle` по типу фигуры.

**Ответ.** Клиентский код не создает фигуры напрямую, а получает их через фабрику.
