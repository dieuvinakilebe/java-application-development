# Лабораторная работа №2

Репозиторий выполнен в формате обычного Java/Maven-проекта. Реализованы все 10 пунктов задания:

1. собственный интерфейс итератора;
2. динамический список;
3. хеш-таблица;
4. Singleton с ленивой потокобезопасной инициализацией;
5. Singleton с жадной инициализацией;
6. стек;
7. очередь;
8. QuickSort и MergeSort;
9. бинарный поиск;
10. Factory Method на примере фигур.

Исходное задание лежит в папке `docs/Лаб_2.pdf`.

## Структура проекта

```text
src/main/java/ru/student/lab2
├── algorithms      # сортировки и бинарный поиск
├── collections     # список, итератор, хеш-таблица, стек, очередь
└── patterns        # Singleton и Factory Method

src/test/java/ru/student/lab2
├── algorithms      # JUnit 5 тесты алгоритмов
├── collections     # JUnit 5 тесты структур данных
└── patterns        # JUnit 5 тесты паттернов
```

## Как запустить тесты

Нужен JDK 17+ и Maven.

```bash
mvn test
```

Или:

```bash
./run_tests.sh
```

## Что проверяют тесты

Тесты написаны на JUnit 5. Для каждого основного пункта есть минимум 3 проверки: обычная работа, граничные случаи и ошибки, например пустой стек, пустая очередь, неправильный индекс, отсутствие элемента при бинарном поиске.

## Кратко по реализации

Реализация сделана без стандартных коллекций Java внутри основных структур данных. Используются массивы и собственные узлы для цепочек в хеш-таблице. Это сделано специально, потому что в задании требуется реализация с нуля.
